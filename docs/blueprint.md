# **App Name**: Harmonic Agreement

## Core Features:

- Smart Contract Scan: Smart Scan: Extract key terms, summarize clauses, and identify unusual provisions from uploaded or pasted contract text.
- Jargon Explanation: Clarity Tool: Explain legal jargon in contracts with adjustable explanation levels (beginner, intermediate, professional).
- Contract Analysis: Contract Comparison: Analyze contract favorability using industry standards, providing general advice and recommendations. The contract is rated in favorability to the user by a value 1-100.
- Favorable Rewrites: Refine Tool: Rewrite contracts with more favorable terms for producers or artists, with an option for aggressive rewrites that remove unfavorable clauses. Offers a copy-to-clipboard function. This is a tool powered by generative AI that incorporates the current text of the agreement and other standard industry info to produce suggestions about contract improvements and clause changes.
- Favorability Gauge: Display a favorability rating on a scale of 1-100, showing the overall bias of the contract towards the user.

## Style Guidelines:

- Primary color: Deep Purple (#4B0082) to reflect sophistication and trust.
- Background color: Dark gray (#333333) provides contrast and a modern feel.
- Accent color: Electric Green (#7CFC00) highlights interactive elements and CTAs.
- Clean, sans-serif fonts such as Open Sans or Roboto for optimal readability.
- Use minimalist line icons to represent different contract sections and actions.
- Maintain a clean, spacious layout with clear section divisions for easy navigation.
- Subtle transition animations and loading indicators for a smooth user experience.
